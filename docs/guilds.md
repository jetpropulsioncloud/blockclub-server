# Guilds

BlockClub currently has three guilds:

## Hearthbound
Warm, agrarian and community-oriented identity.

## Ironsworn
Industrial, martial and craftsmanship-oriented identity.

## Starweavers
Arcane, exploratory and knowledge-oriented identity.

## Design rule
Guild choice should eventually change gameplay, not only color, lore or cosmetics.

Areas where guild identity can matter:
- Starter kits
- mcMMO/profession access
- Contribution priorities
- Frontier roles
- Progression rewards
- Utility and support options

## Chat
- Global
- Guild
- Local

Chat bubbles should appear only for Local chat.
