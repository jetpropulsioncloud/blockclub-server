# Configuration

Store only sanitized configuration examples here.

Recommended naming:
- `plotsquared/`
- `multiverse/`
- `worldguard/`
- `geyser/`
- `itemsadder/`

Never commit passwords, tokens, private keys, database credentials, player data or other secrets.

For production configs, prefer a sanitized `*.example.yml` copy with comments documenting BlockClub-specific changes.
